# College SOS — Backend Setup Guide

## 1. Get Your Free Cloudinary Credentials

1. Go to https://cloudinary.com and sign up (free)
2. After login, go to your **Dashboard**
3. You'll see three values:
   - **Cloud Name**
   - **API Key**
   - **API Secret**

## 2. Add Credentials to .env

Open `backend/.env` and fill in:

```
CLOUDINARY_CLOUD_NAME=your_cloud_name_here
CLOUDINARY_API_KEY=your_api_key_here
CLOUDINARY_API_SECRET=your_api_secret_here
```

## 3. Install Python Dependencies

```bash
cd backend
pip install -r requirements.txt
```

Or inside your venv:
```bash
venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

## 4. Seed the Database

```bash
python seed.py
```

## 5. Run the Backend

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Open http://localhost:8000/docs to verify.

## 6. Flutter — Set the API URL

Edit `lib/services/api_config.dart`:

```dart
// For Android emulator:
const String kBaseUrl = 'http://10.0.2.2:8000';

// For physical Android device (same WiFi):
const String kBaseUrl = 'http://YOUR_PC_IP:8000';

// For Chrome/web:
const String kBaseUrl = 'http://localhost:8000';
```

## 7. Run Flutter

```bash
flutter pub get
flutter run
```

## How Video Upload Works

1. Student records/picks video → selects category/location → taps "SEND SOS"
2. App submits SOS record to MongoDB → gets back `sos_id`
3. App uploads video bytes to `POST /upload/sos-video` with `sos_id`
4. Backend uploads to **Cloudinary** → gets back a CDN URL like:
   `https://res.cloudinary.com/YOUR_CLOUD/video/upload/college_sos/sos/abc123.mp4`
5. URL is stored in MongoDB on the SOS record
6. Admin opens SOS tab → sees video thumbnail (auto-generated by Cloudinary)
7. Admin taps thumbnail → `url_launcher` opens the Cloudinary URL in browser → video plays
